## Design decisions

1. **Wrap the POST, not the GET.** The login-form GET at `async_zp.py:130` /
   `zp.py:108` is already handled (its `NetworkError` message is tested as
   `Failed to fetch login page` and is out of scope). Only the credential
   POST moves onto the shared retry helper, matching the spec and keeping the
   GET tests unchanged.

2. **Re-use the shared helper as-is.** Call
   `fetch_with_retry_async(self._client, login_url_from_form, method='POST',
   data=data, cookies=self._client.cookies, logger=logger)` (sync equivalent
   `fetch_with_retry_sync`). `**kwargs` in the helper are forwarded to
   `client.request()`, which accepts `data` and `cookies`. Default
   `max_retries=3`, `backoff_factor=1.0`; 4xx still re-raise immediately, 5xx
   and `ConnectError`/`TimeoutException` retry. No new helper parameters.

3. **Preserve the user-facing error shape.** On exhaustion the helper raises
   `NetworkError('Failed after 3 attempts: ...')`. `login()` gains
   `except NetworkError as e:` (placed before the `HTTPStatusError` /
   `RequestError` clauses) that re-raises
   `NetworkError(format_network_error('authenticate with Zwiftpower',
   login_url_from_form, e))`. This keeps the `Failed to authenticate with
   Zwiftpower:` message and the `Endpoint:` line from the issue traceback.
   `AuthenticationError` (redirect back to `ucp.php?mode=login`) is a sibling
   of `NetworkError`, not a subclass, so it still propagates untouched. The
   post-response success check and the trailing
   `self.login_response.raise_for_status()` stay as they are.

4. **Timeout is an `__init__` keyword, last and optional.**
   `timeout: float = 30.0`. Stored as `self.timeout` before any client is
   built, then passed as `timeout=self.timeout` in `_create_client()` and in
   the `shared_client=True` construction path (`AsyncZP.__init__` and
   `ZP._shared_client`). Default 30.0 matches `zrdatafetch`/`zdatafetch`/
   `zsdatafetch` and replaces httpx2's implicit 5 s. Existing call sites
   (`AsyncZP()`, `AsyncZP(skip_credential_check=True)`, `shared_client=True`,
   CLI) keep working because the argument is optional and last.

5. **Shared-client timeout is first-writer-wins.** `_shared_client` is a
   class attribute; a pre-existing shared client keeps its original timeout.
   This is existing behavior and unchanged. Tests assert timeout on
   `_create_client()` directly to avoid class-attribute pollution.

6. **Keep the `SECURITY` comment.** The credential payload and the
   credential-bearing SSO URL are never logged. The existing
   `# SECURITY: Do NOT log the data dict or login URL` comment and the
   neutral `'Submitting authentication credentials to login endpoint'`
   message stay.

7. **No CLI flag, config key, retry-count change, or per-request timeout.**
   Spec non-goals.

8. **Fast tests via monkeypatched sleeps.** Login uses the helper's default
   backoff (1.0 s), so retry tests must not actually sleep. Patch
   `shared.http_client.time.sleep` (sync) and
   `shared.http_client.anyio.sleep` (async) to no-ops in those tests. This
   changes no production behavior.

@pytest.mark.anyio
async def test_async_login_retries_transient_post(
  login_page,
  logged_in_page,
  monkeypatch,
):
  """Login POST is retried on a transient read timeout."""
  import shared.http_client as http_client

  async def _noop(_delay):
    return None

  monkeypatch.setattr(http_client.anyio, 'sleep', _noop)

  post_calls = 0

  def handler(request):
    nonlocal post_calls
    if request.method == 'GET':
      return httpx2.Response(200, text=login_page)
    post_calls += 1
    if post_calls == 1:
      raise httpx2.ReadTimeout('timed out')
    return httpx2.Response(200, text=logged_in_page)

  async with AsyncZP(skip_credential_check=True) as zp:
    zp.username = 'testuser'
    zp.password = 'testpass'
    await zp.init_client(
      httpx2.AsyncClient(
        follow_redirects=True,
        transport=httpx2.MockTransport(handler),
      ),
    )
    await zp.login()
    assert zp.login_response is not None
    assert zp.login_response.status_code == 200
    assert post_calls == 2
